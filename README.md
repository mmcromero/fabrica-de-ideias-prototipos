# Fábrica de Ideias — Protótipos

Repositório **público** de visualização de protótipos. Os projetos de desenvolvimento permanecem nos respectivos repositórios privados.

## Estrutura

- `index.html`: vitrine do laboratório.
- `pode-vir/index.html`: demonstração inicial do Pode Vir (marca provisória).

## Regras de publicação
- Publicar somente arquivos estáticos revisados (HTML, CSS, JavaScript e imagens sem informações confidenciais).
- Não copiar código de servidor, chaves, tokens, credenciais, dados pessoais ou documentação interna.
- Cada protótipo fica em sua própria pasta e utiliza caminhos relativos.
- Interfaces são demonstrativas; não oferecem login real, pagamento, gravação ou serviços em produção.
- Alterações de produção no GitHub Pages devem ser verificadas visualmente antes de considerar homologadas.

## Configuração inicial do Pages
No GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

URL esperada após ativação:
- https://mmcromero.github.io/fabrica-de-ideias-prototipos/
- https://mmcromero.github.io/fabrica-de-ideias-prototipos/pode-vir/

A configuração do Pages ainda requer ação manual do proprietário. Este texto não confirma a publicação.
