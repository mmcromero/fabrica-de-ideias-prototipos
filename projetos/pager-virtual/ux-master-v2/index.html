Após instalar uma versão aprovada, abra o aplicativo no caixa, confira a URL HTTPS e selecione “Iniciar ou retomar pareamento”. O computador mostra o QR Code ou código temporário; o gerente confere e autoriza pelo celular. A confirmação do vínculo depende do servidor.
