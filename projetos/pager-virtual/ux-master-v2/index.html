Integração de impressão

Os computadores de caixa enviam pedidos ao Avisaqui. A impressora física continua funcionando de forma independente.

1

Vincular computador

Abra o agente no caixa. Peça ao gerente para ler o QR Code e autorizar o computador pelo celular. O código numérico é uma alternativa.

O pareamento é uma proposta visual em revisão. Não gera credenciais reais.

2

3

Agente Windows

O agente identifica números de pedidos e envia os eventos. No fluxo proposto, não exige CMD nem cópia manual de credenciais no uso comercial.

A configuração e a captura atuais do agente pertencem à integração existente. Pareamento não resolve falhas de captura, e nenhuma impressora é alterada no protótipo.
